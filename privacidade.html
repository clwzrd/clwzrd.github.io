Política de privacidade

Voce Aguentaria Automacao · atualizada em 14 de outubro de 2026

Esta ferramenta é usada apenas pelo dono do canal do YouTube Você Aguentaria? para gerenciar o próprio canal. Ela não tem outros usuários.

Que dados ela acessa

Com a autorização dada pelo dono do canal na tela de login do Google, a ferramenta usa a YouTube Data API para acessar os dados desse único canal: vídeos, Shorts, miniaturas, legendas, playlists, o status do agendamento e os comentários feitos nos vídeos do canal.

Para que ela usa

Só para publicar e gerenciar o conteúdo do próprio canal: enviar e agendar vídeos, colocar miniatura, legenda e playlist, conferir o agendamento e responder comentários em nome do canal.

O que ela não faz

Não vende, não aluga e não compartilha dados com ninguém. Não usa dados para publicidade. Não acessa canais de outras pessoas. Não guarda os dados em servidor nem em banco de dados.

Onde fica a autorização

O token de acesso fica gravado só no computador do dono do canal. Ele pode revogar o acesso a qualquer momento em myaccount.google.com/permissions.

Serviços do Google e do YouTube

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado. Esta ferramenta usa os Serviços de API do YouTube; vale também os Termos de Serviço do YouTube e a Política de Privacidade do Google.
